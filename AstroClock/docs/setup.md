# Своя карта в часах: от чистой платы до работающего экрана

Пошаговый проход. Справочник по флагам и точности лежит в [README](../README.md),
здесь только порядок действий.

Прошивка нигде не собирается автоматически: CI знает про docker-образы бэкенда,
фронта и эфемерид, но не про platformio. Готового `.bin` для скачивания нет,
собирать нужно у себя.

## Что понадобится

- плата ESP32-C3 с круглым дисплеем GC9A01 240×240
- [PlatformIO](https://platformio.org/install/cli) (`pio` в `PATH`)
- дата, время и место рождения
- кабель USB-C

## 1. Создать локальный конфиг

```
cp secrets.ini.example secrets.ini
```

`secrets.ini` лежит в `.gitignore` и в репозиторий не уедет. Натальные данные
в `platformio.ini` не вписываются: репозиторий публичный.

## 2. Вписать свои данные

Секция `[personal]` в `secrets.ini`:

```ini
[personal]
build_flags =
    -D NATAL_YEAR=1984
    -D NATAL_MONTH=9
    -D NATAL_DAY=11
    -D NATAL_HOUR=1
    -D NATAL_MINUTE=40
    -D NATAL_UTC_OFFSET=4.0
    -D NATAL_LAT=55.7558
    -D NATAL_LON=37.6173
    -D HOME_LAT=55.7558
    -D HOME_LON=37.6173
    -D HOME_TZ='"MSK-3"'
```

Три места, где легко ошибиться.

**`NATAL_HOUR` и `NATAL_MINUTE`** — местное время рождения, как записано
в свидетельстве, без пересчёта в UTC.

**`NATAL_UTC_OFFSET`** — смещение, которое действовало в том месте и в тот
момент, с декретным и летним временем. Для Москвы сентября 1984 это UTC+4,
а не привычные UTC+3: летнее время отменили только 30 сентября. Ошибка на час
двигает асцендент примерно на 15°, то есть на целый знак.

**`NATAL_LON` и `HOME_LON`** — долгота восточная положительная, в коде поле
так и называется, `lonEast`. Западное полушарие пишется со знаком минус.
Широта северная положительная.

`HOME_*` описывают место, где стоят сами часы, а не место рождения. Часовой
пояс в формате POSIX TZ: Москва `MSK-3`, Амстердам
`CET-1CEST,M3.5.0,M10.5.0/3`.

## 3. Проверить, что конфиг подхватился

```
pio project config
```

В секции `env:esp32-c3-devkitm-1` должны появиться ваши `-D NATAL_*`. Если их
нет, файл лежит не там: `secrets.ini` кладётся рядом с `platformio.ini`,
и подхватывает его строка `extra_configs = secrets*.ini`.

Проверка не косметическая. Без файла сборка не падает, а молча берёт запасные
значения из [src/config.h](../src/config.h) — эпоху J2000 в Гринвиче. Часы
включатся и покажут чужую карту.

## 4. Прошить по USB

Подключить плату и найти порт:

```
pio device list
```

Залить:

```
pio run -t upload
```

Порт обычно определяется сам. Если нет, добавить
`--upload-port /dev/cu.usbmodemXXXX`.

## 5. Проверить на устройстве

Кнопка на GPIO9:

- короткое нажатие переключает экран по кругу: биwheel, небо, список транзитов
- нажатие дольше 0.8 с меняет цветовую тему, их девять

Режим и тема переживают перезагрузку через NVS.

Асцендент на биwheel прибит к левому краю. Сверьте его знак с любым
калькулятором натальных карт: сошлось — значит `NATAL_UTC_OFFSET` выставлен
верно. Это самая дешёвая проверка всей конфигурации.

## Время без сети

По умолчанию WiFi в образ не линкуется совсем. Часы стартуют от момента сборки
и берут большее из него и сохранённого в NVS времени. После долгого простоя
карта будет от даты последнего включения, и на экране рядом со временем стоит
пометка «восстановлено из NVS (не проверено)».

Чтобы включить NTP:

```
export ASTRO_WIFI_SSID='...' ASTRO_WIFI_PASS='...'
pio run -t upload
```

Пароль идёт переменной окружения и в исходники не попадает: прошлый лежал прямо
в `main.cpp` и уехал в публичный репозиторий вместе с ним.

Цена сети — размер образа: 69.9% флеша против 29.6% без неё.

## Заливка по воздуху

Пока правите код, кабель можно отложить:

```
export ASTRO_WIFI_SSID='...' ASTRO_WIFI_PASS='...' ASTRO_OTA=1
pio run -e ota -t upload
```

Устройство отзывается на `astroclock.local` через mDNS, IP на секунду
показывается на экране после подключения.

`ASTRO_OTA` отделён от WiFi нарочно: с ним радио остаётся включённым весь
аптайм, тогда как обычная сборка поднимает его на пару секунд ради NTP и гасит.
Одна переменная окружения выключает OTA обратно, трогать код не нужно.

Пароль на заливку опционален и статически в `platformio.ini` не подставляется:

```
PLATFORMIO_UPLOAD_FLAGS="--auth=$ASTRO_OTA_PASS" pio run -e ota -t upload
```

## Если что-то не так

**Часы показывают карту 1 января 2000 года.** `secrets.ini` не подхватился,
работают запасные значения из `config.h`. Вернуться к шагу 3.

**Асцендент не сходится с калькулятором.** Почти всегда `NATAL_UTC_OFFSET`:
проверьте, какое время действовало в месте рождения именно в ту дату, а не
какое действует сейчас.

**Планеты стоят правильно, а дома и асцендент нет.** Долгота с обратным
знаком, см. `lonEast` в шаге 2. Положения планет от долготы наблюдателя
не зависят, а куспиды, асцендент и границы лунных суток зависят, поэтому
ошибка знака бьёт только по ним.

**Дата и время едут после перезагрузки.** Ожидаемо для сборки без WiFi,
см. «Время без сети».
