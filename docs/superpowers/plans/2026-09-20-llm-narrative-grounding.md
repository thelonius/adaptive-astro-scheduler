# Сверка LLM-нарративов с эфемеридами

**Статус на 2026-09-20:** этапы 1 и 2 сделаны, лежат в рабочем дереве (не закоммичены).
Этап 3 и доработки ниже — открыты. Бэклог: [docs/BACKLOG.md](../../BACKLOG.md).

## Зачем

Промпт нарративов просит модель называть планеты, знаки и аспекты дня, а проверка
после генерации смотрела только форму JSON. Текст «Меркурий ретроградный» в день,
когда Меркурий директен, проходил насквозь. Вдобавок модель физически не могла
опереться на данные: снапшот содержал знак Луны, фазу, знак Солнца, список
ретроградных и до шести аспектов с орбом ≤ 4°, позиций остальных планет в нём не было.

## Известное ограничение разбора

Утверждения ищутся регулярками по стеблям слов, без морфологии. Для русского
заведены падежные окончания знаков и планет, отрицание ловится только простое
(«не ретроградный»). Из-за ASCII-семантики `\b` и `\w` в JS кириллические шаблоны
пишут границы сами: `(?![а-яё])` в конце стебля и `[а-яё]*` вместо `\w*`.
Сложные обороты («Луна уходит из Рака») разбор пропустит, но пропуск даёт
`supported` по умолчанию, то есть не ломает текст, а лишь не ловит ошибку.
